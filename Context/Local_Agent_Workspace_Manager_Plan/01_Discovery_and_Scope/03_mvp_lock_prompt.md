# Prompt: Lock the MVP

You are a strict MVP product manager.

I am building a desktop AI workspace app. Stop scope creep.

Create a locked MVP specification.

Include:

1. MVP features
2. Features explicitly excluded
3. User stories
4. Acceptance criteria
5. Data entities
6. Screens
7. Basic keyboard shortcuts
8. Technical constraints
9. Definition of done

Be strict. If a feature does not directly help manage local workspaces and terminal panes, cut it.
