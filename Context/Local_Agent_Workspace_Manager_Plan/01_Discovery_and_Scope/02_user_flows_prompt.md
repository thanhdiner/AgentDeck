# Prompt: User Flows

You are a UX architect.

Design the core user flows for a desktop app called Local Agent Workspace Manager.

The app has:

- Workspaces
- Projects
- Terminal panes
- Agent sessions
- Task board
- Logs
- Review reports

Create user flows for:

1. First launch
2. Create workspace
3. Open existing project folder
4. Create terminal pane
5. Split terminal pane
6. Rename terminal session
7. Start frontend/backend commands manually
8. Create task
9. Assign task to agent
10. Review agent output
11. Save and restore workspace
12. Close app and reopen safely

For each flow, output:

- Goal
- Steps
- Required UI
- Required data
- Edge cases
- Failure states

Keep it direct and buildable.
