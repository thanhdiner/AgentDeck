# Prompt: Workspace CRUD

You are a full-stack desktop app developer.

Implement workspace CRUD.

A workspace has:

- id
- name
- rootPath
- createdAt
- updatedAt
- lastOpenedAt
- layoutJson
- settingsJson

Features:

1. Create workspace from local folder
2. List workspaces
3. Open workspace
4. Rename workspace
5. Delete workspace from app database only, never delete files
6. Persist last opened workspace
7. Show workspace in sidebar

Use SQLite for metadata.

Output complete implementation steps and files.
