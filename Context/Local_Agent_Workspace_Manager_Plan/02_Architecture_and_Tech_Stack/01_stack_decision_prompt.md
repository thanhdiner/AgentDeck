# Prompt: Choose the Tech Stack

You are a senior desktop app architect.

Choose the best stack for a local-first desktop app with multi-pane terminal support.

Default preference:

- Electron
- React
- TypeScript
- xterm.js
- node-pty
- SQLite
- filesystem logs

Compare this stack against:

- Tauri + React + Rust
- C# WPF/WinUI
- JavaFX
- Pure web app

Output:

1. Recommended stack
2. Why this stack
3. Tradeoffs
4. Package list
5. Project structure
6. Security risks
7. Performance risks
8. Long-term migration risks

Be practical. Optimize for fast solo development, not theoretical perfection.
