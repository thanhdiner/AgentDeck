You are a workflow engineer.

Implement task-to-terminal linking.

User should be able to:

1. Select a task
2. Pick an active terminal session
3. Link them
4. View linked session from task
5. View linked task from terminal pane
6. Save this link in database

Output:

- Data changes
- UI changes
- IPC changes
- Edge cases
