# Prompt: Task Model

You are a product engineer.

Implement a simple task board for the app.

Task fields:

- id
- workspaceId
- title
- description
- status: backlog | active | review | done | blocked
- priority: low | medium | high
- assignedAgentId
- linkedSessionId
- createdAt
- updatedAt

Features:

- Create task
- Edit task
- Delete task
- Change status
- Assign terminal session
- Assign agent profile later
- Show tasks in right panel

Output data model, UI, and IPC implementation.
