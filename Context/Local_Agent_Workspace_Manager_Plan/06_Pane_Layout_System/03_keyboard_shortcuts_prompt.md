# Prompt: Keyboard Shortcuts

You are a desktop UX engineer.

Design and implement keyboard shortcuts.

Required shortcuts:

- New terminal
- Split vertical
- Split horizontal
- Close pane
- Focus next pane
- Focus previous pane
- Toggle sidebar
- Toggle inspector
- Command palette
- Rename session

Output:

1. Shortcut table
2. Conflict rules
3. Implementation pattern
4. User settings for shortcuts
5. React hook code
