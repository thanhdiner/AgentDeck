# Prompt: Split Pane Layout

You are a frontend architecture expert.

Implement a multi-pane layout system.

Features:

- Split pane vertically
- Split pane horizontally
- Resize panes
- Close pane
- Maximize pane
- Restore pane
- Drag pane focus
- Persist layout as JSON

You may use react-mosaic-component or implement a custom layout.

Output:

1. Recommended approach
2. Layout data model
3. React state management
4. Component structure
5. Save/restore logic
6. Edge cases
