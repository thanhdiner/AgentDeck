# Prompt: Review Report Generator

You are an AI workflow engineer.

Design a review report generator.

The report should summarize:

- Task
- Agent profile used
- Commands run
- Files likely changed
- Errors found
- Final status
- Next recommended action

For MVP, generate report from terminal logs and user notes. Do not require deep code intelligence.

Output:

- Markdown report format
- Data source list
- UI flow
- Storage strategy
- Example report
