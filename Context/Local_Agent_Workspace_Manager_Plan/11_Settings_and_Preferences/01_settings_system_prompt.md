# Prompt: Settings System

You are an app settings engineer.

Implement settings.

Settings categories:

- Appearance
- Default shell
- Default workspace path
- Terminal font size
- Terminal font family
- Permission mode
- Agent profiles
- Log retention
- Shortcuts

Requirements:

- Store in SQLite or JSON config
- Renderer reads through safe IPC
- Settings update live where possible
- Validate all settings

Output data model, UI, and IPC implementation.
